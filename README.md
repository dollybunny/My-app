# مصروفي — تطبيق ويب تقدّمي (PWA)

تطبيق عربي (RTL) لتتبّع المصروفات والدخل، وأهداف الادخار، وتحديات الادخار.
يعمل على الجوال، ويمكن تثبيته على الشاشة الرئيسية، ويعمل دون إنترنت بعد أول زيارة.

## هيكل الملفات

```
masroofi-pwa/
├── index.html                  الصفحة الرئيسية (في جذر المستودع)
├── manifest.webmanifest        ملف الـ manifest (اسم التطبيق، الألوان، الأيقونات، الاختصارات)
├── sw.js                       Service Worker (العمل دون إنترنت)
├── .nojekyll                   يمنع معالجة Jekyll في GitHub Pages
├── css/
│   └── style.css               التصميم
├── js/
│   └── app.js                  منطق التطبيق
└── icons/
    ├── icon.svg                أيقونة متجهة
    ├── icon-192.png            أيقونة Android
    ├── icon-512.png            أيقونة كبيرة
    ├── icon-maskable-512.png   أيقونة تتكيّف مع أشكال Android
    ├── apple-touch-icon.png    أيقونة iPhone
    └── favicon-32.png          أيقونة تبويب المتصفح
```

> مهم: يجب أن يكون `index.html` و`manifest.webmanifest` و`sw.js` في **جذر** المستودع (وليس داخل مجلد فرعي).

## الرفع على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `masroofi`).
2. ارفع **محتويات** المجلد `masroofi-pwa` (وليس المجلد نفسه) إلى الفرع `main`، بما فيها الملف المخفي `.nojekyll`.
3. من المستودع: **Settings ← Pages ← Build and deployment**
   اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة تقريباً يصبح الرابط: `https://اسم-المستخدم.github.io/masroofi/`

كل المسارات نسبية، فيعمل التطبيق داخل مجلد المستودع دون أي تعديل.

## التثبيت على الجوال

- **Android (Chrome):** قائمة ⋮ ← «تثبيت التطبيق»، أو من الإعدادات داخل التطبيق ← «تثبيت التطبيق».
- **iPhone (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات

- البيانات تُحفظ في `localStorage` على جهاز المستخدم فقط (لا خادم ولا حساب). يمكن تصدير نسخة احتياطية من الإعدادات.
- خط Cairo يُحمَّل من Google Fonts في أول زيارة ثم يُخزَّن للعمل دون إنترنت. إن لم يتوفر تُستخدم خطوط النظام العربية.
- التذكير اليومي يظهر عند فتح التطبيق إذا لم تسجّل مصروفاً اليوم. التنبيهات الفعلية في الخلفية تتطلب خادم Push، وهو غير متاح في GitHub Pages.
- عند تعديل أي ملف لاحقاً، غيّر `VERSION` في `sw.js` (مثلاً `masroofi-v2.0.1`) كي يحدّث الجوال النسخة المخزّنة.
